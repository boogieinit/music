# Native Instruments

Tools for managing Native Instruments software on a Mac.

New to the Terminal? Start with **Getting started** in the [main README](../README.md#getting-started), then open Terminal in this folder.

| Script | What it does | Details |
|--------|--------------|---------|
| [`uninstall_ni_product.sh`](uninstall_ni_product.sh) | Removes a Native Instruments product from a Mac: finds its app, plug-in, preference and library files, lists them, and deletes them after you confirm. macOS only. | [uninstall_ni_product.md](uninstall_ni_product.md) |
